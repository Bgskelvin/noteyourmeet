# NoteYourMeet

Aplikasi web privat untuk tim: rekaman meeting → transkrip + speaker → notulen otomatis.

Rencana lengkap, keputusan teknologi, dan status terakhir ada di @PROJECT_PLAN.md — baca dulu, terutama bagian **10. Status & Langkah Berikutnya**.

Aturan kerja:
- Bahasa komunikasi: Bahasa Indonesia.
- Ikuti stack & struktur folder di PROJECT_PLAN.md; jika ingin mengubah keputusan, catat di bagian **11. Log Keputusan**.
- Setelah menyelesaikan tahap, update bagian 8 (checklist) dan 10 (status) di PROJECT_PLAN.md.
- Jangan commit file `.env` atau API key.
